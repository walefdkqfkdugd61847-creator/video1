VideoUpscale AI — إصلاح خطأ Worker في Vercel
================================================

لماذا حدث الخطأ؟
الصفحة السابقة كانت تستورد @ffmpeg/ffmpeg مباشرة من unpkg. المتصفح يمنع أحيانًا إنشاء Worker من نطاق مختلف (Cross-Origin Worker). الحل الأفضل هو بناء المشروع باستخدام Vite وحزمة npm، حتى يتم تضمين worker.js في ملفات الموقع على نفس النطاق.

النشر من الموبايل عبر GitHub + Vercel
------------------------------------
1) أنشئ مستودع GitHub جديدًا من المتصفح.
2) ارفع محتويات هذا المجلد كاملة، وليس ملف ZIP نفسه:
   - package.json
   - index.html
   - مجلد src وبداخله main.js وstyle.css
3) في Vercel اختر Add New → Project ثم استورد مستودع GitHub.
4) الإعدادات:
   Framework Preset: Vite
   Build Command: npm run build
   Output Directory: dist
   Install Command: npm install
5) اضغط Deploy وانتظر Ready، ثم افتح رابط الموقع.
6) جرّب مقطعًا قصيرًا بدقة HD أولًا.

ملاحظات:
- يتطلب تنزيل محرك FFmpeg اتصال إنترنت في أول استخدام.
- ملف الفيديو تتم معالجته في المتصفح ولا يُرفع إلى سيرفر معالجة.
- تغيير الأبعاد إلى 4K ليس تحسينًا بالذكاء الاصطناعي ولا يعيد تفاصيل مفقودة.
- معالجة 4K على الموبايل قد تفشل بسبب الذاكرة أو الوقت؛ ابدأ بـ720p.
- هذه نسخة أولية تحتاج اختبارًا على جهازك ومتصفحك.
